One sharp line about screen time, written for the
[One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2)
competition on make.fun.

## Run

Requires Node.js 22. No dependencies, no network access.

```sh
node main.ts
```

This writes a single line to `/output/entry.txt`:

> My phone's screen-time report called me 'a heavy user', so I reported it for harassment and it apologized in a push notification.

## Cara menjalankan
Jalankan dengan Deno: `deno run --allow-read --allow-write main.ts`
Hasilnya tersimpan di `/output/entry.txt`.
